# 學力檢測 自己來訂正

縣市學生學習能力檢測的互動檢討網頁。

- 首頁：https://teacher-liujikan.github.io/literacy-review/
- 數學：https://teacher-liujikan.github.io/literacy-review/math/
  - 三～六年級：111～115 年
  - 首頁：選年級 →「線上測驗／紙本檢討」切換 → 依年度作答或印考卷 → 老師挑題
  - 線上測驗：整卷在平板上作答，交卷自動改；紙本檢討：整卷下載 Word／列印 PDF，學生寫完上網對答案
  - 分步詳解、借位直式動畫、錯題測驗、徽章收集
  - 老師挑題練習（依南一／康軒／翰林單元或學習內容），可匯出 Word／PDF
  - 原始考古題下載（紙本模式的年度卡片上）：`math/files/`（題本、答案、試題疑義）
- 國語：製作中

作答紀錄只存在學生自己裝置的瀏覽器（localStorage），不會上傳。
